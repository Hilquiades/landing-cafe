# Landing page – Café Brasa

Fiz esta página para praticar o que mais aparece nos pedidos de freelancer: uma landing page simples, bonita no celular e que leva o cliente direto para o WhatsApp. O café é fictício, mas o código serve de base para qualquer pequeno negócio.

**Ver ao vivo:** https://hilquiades.github.io/landing-cafe/

## O que eu quis acertar
- Que funcione bem no celular primeiro (é de lá que vem a maioria dos clientes)
- Um formulário que monta o pedido e abre o WhatsApp, sem precisar de servidor
- HTML organizado e acessível, sem framework: abre o `index.html` e já funciona

## Para adaptar a um cliente
Mude textos e cores (as variáveis estão no topo do `style.css`) e o número de WhatsApp no `script.js`.
